**Abstract 1**

Traditional malware detection systems rely heavily on static signature-based analysis, which struggles to identify polymorphic, obfuscated, or previously unseen threats, and often provides analysts with little more than a binary "malicious/benign" verdict devoid of actionable context. This gap leaves security teams without insight into *how* a threat operates, *why* it was flagged, or *what* remediation steps are appropriate — a shortfall increasingly emphasized in recent literature advocating dynamic, behavior-driven analysis over static methods. To address this, we propose **IsoLens**, a lightweight, modular malware analysis platform that executes suspicious files within isolated virtual machine environments and performs comprehensive runtime behavioral monitoring. The methodology involves automatically provisioning a clean VM snapshot, transferring and executing the sample, and capturing multi-source telemetry — including process trees, file system and registry activity, network/DNS traffic, loaded modules, persistence mechanisms, and periodic screenshots — using tools such as Sysmon, Windows Event Logs, and PowerShell logging. These behavioral artifacts are then processed through an AI-driven analysis pipeline that extracts Indicators of Compromise (IOCs), maps observed actions to MITRE ATT&CK techniques, computes a weighted behavioral risk score, and generates human-readable, explainable justifications for each classification rather than an opaque verdict.

The resulting system produces structured, analyst-friendly threat intelligence reports comprising executive and technical summaries, process-tree and timeline visualizations, IOC tables, MITRE mappings, and recommended remediation actions, with future extensions planned for automatic YARA rule generation, multi-agent AI analysis, and cross-sample behavioral similarity comparison. By combining dynamic sandboxing, rich behavioral feature extraction, and explainable AI within a single accessible, privacy-preserving platform, IsoLens is intended for use in educational institutions, small security teams, and research settings where commercial sandboxing solutions (e.g., ANY.RUN, Cuckoo Sandbox) are often cost-prohibitive or lack transparency in their decision-making. The project's contribution lies not in any single component but in their integration: transforming raw execution telemetry into interpretable, actionable threat intelligence, thereby reducing manual reverse-engineering effort, improving analyst trust through explainability, and enabling faster, more informed incident response.






Abstract 2

The increasing prevalence of unknown and untrusted software has created a growing need for efficient and accessible malware analysis solutions capable of identifying malicious behavior while ensuring system safety. Conventional approaches often rely on manual investigation, cloud-based analysis platforms, or resource-intensive infrastructures, which may introduce limitations related to scalability, privacy, cost, and accessibility. This project presents IsoLens, an open-source, lightweight, and modular malware analysis platform that performs automated behavioral analysis by executing suspicious files inside an isolated virtual machine environment. The proposed system employs dynamic analysis techniques to observe runtime behavior through comprehensive monitoring of processes, file system activity, registry modifications, network communications, user interactions, and other behavioral artifacts. The collected data is further enriched using security mechanisms such as YARA-based detection, Indicators of Compromise (IOCs) extraction, and MITRE ATT&CK technique mapping to provide structured behavioral intelligence.

The proposed methodology combines virtualization, behavioral monitoring, modular data collection, and artificial intelligence to automate the malware analysis workflow. A dedicated agent operating within the sandbox environment gathers execution artifacts and monitoring outputs, which are processed by multiple analysis modules to identify suspicious activities and generate structured security intelligence. A locally hosted or remotely accessible Large Language Model (LLM) interprets the collected evidence to produce explainable threat summaries, behavioral risk assessments, natural language reports, and actionable recommendations. The modular architecture enables future extensibility while maintaining a lightweight implementation suitable for academic and small-scale research environments. By integrating dynamic behavioral analysis with AI-assisted threat intelligence generation, IsoLens provides an accessible platform for malware research, cybersecurity education, secure analysis of suspicious software, and early threat detection, thereby reducing the dependency on manual investigation and improving the interpretability of malware analysis results.



Abstract 3

The rapid growth of unknown and untrusted software has significantly increased the need for reliable and automated malware analysis solutions capable of identifying malicious behavior while ensuring system safety. Existing malware analysis platforms are often cloud-dependent, resource-intensive, or inaccessible to students and small-scale researchers, highlighting the demand for a lightweight, privacy-preserving, and locally deployable alternative. This project presents IsoLens, an open-source, modular malware analysis platform that executes suspicious files inside an isolated virtual machine to safely observe and analyze their runtime behavior. The system employs dynamic behavioral analysis by continuously monitoring process creation, file system modifications, registry changes, network communications, user interface interactions, and other system activities through multiple monitoring components. The collected behavioral artifacts are enriched using detection techniques such as YARA rule matching, Indicators of Compromise (IOC) extraction, and behavioral correlation to provide comprehensive visibility into malware execution.

The proposed architecture integrates virtualization with an agent-based monitoring framework and an AI-assisted threat intelligence module to automate malware investigation. Behavioral data collected during execution is processed to generate explainable natural language summaries, malware classifications, risk scores, MITRE ATT&CK technique mappings, and structured analysis reports containing execution timelines, process trees, screenshots, and extracted forensic artifacts. By combining dynamic sandboxing, behavioral monitoring, explainable artificial intelligence, and automated threat intelligence generation within a modular and extensible framework, IsoLens reduces the dependence on manual malware investigation while improving analyst understanding of malicious software behavior. The platform is intended for cybersecurity education, malware research, security operations, and digital forensic investigations, providing an accessible foundation for future research in AI-assisted malware analysis and intelligent threat detection.
